# Перенос хакатона

## Когда применять

Задача требует изменить мир: забронировать площадку, назначить слоты всем командам, разослать письма.
На вопрос «какой статус» или «какой слот у команды» навык не нужен: достаточно прочитать данные и ответить.

## Порядок бесконфликтного распределения слотов

1. Раздели команды по трекам. У каждого трека свой зал забронированной площадки и свой ментор.
2. Внутри трека отсортируй команды по идентификатору.
3. Возьми окна ментора трека по порядку и выдай по одному каждой команде: первой команде первое окно,
   второй второе и так далее. Это менторские сессии. Окно должно быть и у ментора, и у зала.
4. Возьми окна зала, которых нет среди окон менторов, и так же по порядку выдай по одному каждой команде.
   Это питчи.
5. Проверь перед вызовом: в одном зале нет двух команд в одно окно, у одного ментора нет двух команд
   в одно окно, у команды менторская сессия и питч в разных окнах.
6. Передай все команды одним вызовом инструмента назначения слотов. Если он вернул ошибки,
   исправь только названные команды и повтори весь набор.
7. Письма отправляй после того, как слоты записаны: в письме команде обязательно время начала
   её менторской сессии и питча.

## Сводный бюллетень

Последний ответ — только бюллетень по шаблону ниже, без вступлений и без markdown.
Заголовки секций в квадратных скобках пиши дословно. Строку про конфликты пиши дословно
и только если инструмент назначения слотов принял набор без ошибок.

```text
[ПЛОЩАДКА]
<название площадки> (<идентификатор>), стоимость <сумма> KZT, бронь <номер брони>

[СЕТКА СЛОТОВ]
<команда> | <зал> | ментор <имя> | сессия <окно> | питч <окно>
... по одной строке на каждую команду
Конфликтов расписания: 0

[СТАТУС РАССЫЛКИ]
Командам отправлено: <число> из <число>
Менторам отправлено: <число> из <число>
```
